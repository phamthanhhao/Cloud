## Hướng dẫn chạy

1. Tải source code về máy.

2. Mở file BeeDienLanh.sln bằng Visual Studio.

3. Mở SQL Server Management Studio.

4. Chạy file Database/BeeDienLanh.sql để tạo cơ sở dữ liệu.

5. Sửa DefaultConnection trong appsettings.json phù hợp với SQL Server trên máy.

6. Build project.

7. Run project.
